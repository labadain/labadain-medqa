To improve Tetun accuracy, follow the Tetun grammar rules below:

1. Overview of the Official Tetun Orthography
1.1. Tetun vowels: a, e, i, o, u.
1.2. Tetun consonants and symbols: b, d, f, g, h, j, k, l, ll, m, n, ñ, p, r, rr, s, t, ', v, x, z.
1.3. Tetun uses accented vowels to indicate stress: á, é, í, ó, ú.
1.4. The letters c, q, w and y are not used in Tetun, except for proper names and international symbols.
1.5. Tetun used hypens to indicate mono-semantic compound words.


2. Basic rules for converting Portuguese-derived words into Tetun (Portuguese -> Tetun):
2.1. nh -> ñ (e.g.: linha -> liña)
2.2. lh -> ll (e.g.: falha -> falla)
2.3. á -> á (e.g., máquina -> mákina)
2.4. ê, é -> é (e.g.: médico -> médiku)
2.5. í -> i (e.g., nível -> nivel)
2.6. ó, ô -> ó (e.g.: avô -> avó, robô -> robó)
2.7. ú -> ú (e.g.: público -> público)
2.8. ch -> x (e.g.: chamada -> xamada)
2.9. sc -> x (e.g., piscina -> pixina)
2.10. g (before e, i) -> j (e.g., geral -> jerál)
2.11. g (before a, o, u), gu -> g (e.g., governo -> governu)
2.12. s (between vowels) -> z (e.g., visita -> vizita)
2.13. ss -> s (e.g., professor -> profesór)
2.14. c (before e, i) -> s (e.g.: centro -> sentru)
2.15. ç (before a, o, u) -> s (e.g., praça -> prasa)
2.16. x -> s (e.g., máximo -> másimu)
2.17. xc -> s (e.g., excelente -> eselente)
2.18. qu -> k (e.g., qualidade -> kualidade)
2.19. c (before a, o, u) -> k (e.g.: cultura -> kultura)
2.20. ão -> aun (e.g.: avião, aviaun)


3. Basic rules for Tetun word endings:
3.1. or -> ór (e.g.: professor -> profesór)
3.2. al -> ál (e.g., internacional -> internasionál)
3.3. el -> él (e.g.: hotel -> otél)
3.4. o -> u (e.g.: livro -> livru)
